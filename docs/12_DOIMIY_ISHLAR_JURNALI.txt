2026-09-11 — Offline va Windows EXE bosqichi boshlandi
Talab: internet uzilganda filial lokal ishlaydi; internet qaytganda server
bilan almashadi. Har filialda bitta yozuvchi lokal backend ishlaydi.
Mavjud React, Python va markaziy PostgreSQL saqlanadi.

Tekshirilgan fayllar: backend/app/db.py, models.py, main.py,
routes_sales.py, common.py, security.py, backend/tests/conftest.py.
Aniqlangan holat: barcha moliyaviy amallar commit bilan tugaydi;
PostgreSQLdagi row lock SQLite uchun yetarli emas. Lokal bazada yozish
tranzaksiyalarini BEGIN IMMEDIATE yordamida ketma-ket bajarish kerak.

Bosqichlar: 1) lokal tranzaksiya va doimiy yuborish navbati;
2) qurilmani ro‘yxatga olish, server qabul qilish va katalogni olish;
3) avtomatik worker va interfeys holati; 4) Electron/Python paketlash;
5) internet uzilishi, takroriy yuborish va ikki filial sinovlari.
Hozir EXE va to‘liq sinxronlash tayyor deb hisoblanmaydi.
