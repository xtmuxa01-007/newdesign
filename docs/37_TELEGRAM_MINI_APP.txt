shu qismning oldingi gridi saqlanadi. Excel fayllarning yaxshilangan bezagi

Boshliqning birinchi ekrani filiallarning bugungi va oy boshidan tushumini

SERVERGA SOZLASH
Bot tokeni kod, frontend, URL parametri yoki releasega yozilmaydi. GitHubdagi
xtmuxa01-007/marva Secrets ichida TELEGRAM_BOT_TOKEN saqlanadi. Main deployi
scripts/configure_telegram.py orqali qisqa muddatli GitHub OIDC bilan
/api/telegram/configure ga tokenni HTTPSda yetkazadi. Faqat ushbu repo IDsi,
main refi va ci-cd.yml workflow imzosi qabul qilinadi. Doimiy GitHub tokeni
serverga yuborilmaydi. Tokenni log yoki xatoga chiqarmang.

API token va tasodifiy webhook sirini alohida integrations_data Docker
volume ichida /app/integrations/telegram.json ga saqlaydi (0600). Bu papka
public uploads, foydalanuvchi AppData yoki biznes bazasi emas. Volume va
tokenni oddiy kod tozalash yoki deployda o‘chirmang. Backend Docker konteksti
va Git ignore lokal integrations papkasini chiqarib tashlaydi.

Webhook /api/telegram/webhook da mustaqil X-Telegram-Bot-Api-Secret-Token
tekshiriladi. Faqat shaxsiy chatdagi /start va /helpga CRM havolasi qaytariladi;
bot orqali savdo, qarz yoki hisob mutatsiyasi bajarilmaydi. /start va /help
oldindan tasdiqlangan qabul qiluvchilar ro‘yxatidagi username egasining
doimiy numeric Telegram IDsini kunlik hisobotga bir marta bog‘laydi.
Har bir odamga ismiga mos salomlashuv, kechagi savdo puli/kg va kecha kun
yakunidagi ombor puli/kg yuboriladi: 38_TELEGRAM_KUNLIK_HISOBOT.txt.
Chatga qayta yozmasdan ulanish uchun Mini App ochilganda initData bir marta
shu origin serveriga yuboriladi. Bot-token HMAC imzosi va 24 soatlik sana
tekshirilgach, allowlistdagi odamning faqat signed user.id qiymati bog‘lanadi.
Bu CRMga login yoki biznes ma’lumotlarini o‘qish huquqini bermaydi; javob
faqat ulanish belgisi. Oddiy web/EXE bu so‘rovni yubormaydi. Xato/timeout
ilova ishlashiga ta’sir qilmaydi; token va initDataUnsafe ishlatilmaydi.

Native Telegramda va oddiy web/EXEda seans cookie Strict qoladi. Telegram
Web iframe loginida faqat secure server, mos Origin va telegram-web client
belgisi bilan SameSite=None; HttpOnly, parol tekshiruvi va CSRF saqlanadi.
Brauzerning uchinchi tomon cookie cheklovi Telegram Webga ta’sir qilishi mumkin;
native Telegram Mini App odatiy yuqori darajadagi WebViewdan foydalanadi.
Mini App HTML faqat web.telegram.org iframeiga ruxsat beradi; oddiy sahifa
frame-ancestors 'none' bilan qoladi. Telegram SDKdan boshqa yangi script
manbalariga ruxsat berilmaydi.
