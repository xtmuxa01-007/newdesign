Eski savdo, qarz, ombor, mahsulot, ta'minotchi, filial, seans, sync qurilmalari tozalanadi.

Eski offline PC bazalarini yangi markazga yubormang; ular alohida eski tarixdir.

scripts/reset_server_database.py faqat server konsolida ishlaydi. HTTP reset API yo'q.
Avval so'nggi CI/CD muvaffaqiyatli tugasin. Reset paytida deploy/push qilmang;
savdoni to'xtating, foydalanuvchilar web/EXEni yopsin. API vaqtincha to'xtaydi.

Aniqlangan server: /opt/marva; Docker project: marva-crm.
Compose: /opt/marva/compose.yaml va /etc/marva/compose.prod.yaml.
ENV_FILE o'rniga serverdagi haqiqiy env fayli yo'li qo'yiladi; mazmuni chatga yuborilmaydi.

Faqat ko'rish:
  cd /opt/marva
  python3 scripts/reset_server_database.py preview --project marva-crm --compose-file /opt/marva/compose.yaml --compose-file /etc/marva/compose.prod.yaml --env-file ENV_FILE --owner abduqodir

Bajarish (avval previewdagi hisob va yozuvlar sonini tekshiring):
  python3 scripts/reset_server_database.py apply --project marva-crm --compose-file /opt/marva/compose.yaml --compose-file /etc/marva/compose.prod.yaml --env-file ENV_FILE --owner abduqodir

Serverdagi deploy qulfini ham oling: buyruq oldiga
  flock -w 900 /run/lock/marva-deploy.lock
qo'shing. Shunda avtomatik deploy bilan reset bir vaqtda ishlamaydi.
Apply hisob va sonlarni ko'rsatadi; zaxira tekshirilgach aynan RESET ... kodini so'raydi.
Tasdiqni yozishdan avval zaxira papkasini boshqa PCga nusxalash mumkin.
Tasdiqsiz hech narsa o'chmaydi. Skript quyidagi tartibda ishlaydi:
1. API to'xtaydi. Baza dastlabki tekshiruvdan o'zgargan bo'lsa bekor qiladi va APIni qaytaradi.
2. PostgreSQL custom dump + rasm arxivi + SHA256 manifest backups/reset-... ga yoziladi.
3. Dump yangi tin_reset_verify_UUID bazasiga pg_restore orqali tiklanadi.
   Barcha jadval sonlari va saqlanadigan hisob asl nusxa bilan taqqoslanadi.
4. Faqat zaxira tekshiruvi va interaktiv tasdiqdan keyin barcha bog'liq yozuvlar bitta tranzaksiyada o'chadi.
   Foreign keylar o'chirilmaydi. Hisob/parol va qolgan yozuvlar tekshiriladi.
5. Faqat yordamchi tekshiruv bazasi olib tashlanadi; API qayta yoqiladi.

Zaxira/dump/restore xatosida reset bajarilmaydi. Reset tranzaksiyasidagi xatoda rollback.
Resetdan keyin /api/health va eski parol bilan loginni tekshiring; filiallar, mahsulotlar
va xodimlarni yangidan yarating. Zaxira papkasini serverdan tashqariga ham ko'chiring.
Backup maxfiy biznes ma'lumotlari va xeshlangan parollarni saqlaydi; Gitga yuborilmaydi.
Eski ma'lumot kerak bo'lsa dump va rasmlarni alohida projectga tiklang (07/20-hujjatlar).
Ishlayotgan yangi bazani tekshirmasdan eski dump bilan almashtirmang.
